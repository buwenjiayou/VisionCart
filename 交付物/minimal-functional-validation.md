# VisionCart 最小功能验证用例集

本文档用于评委在 15-25 分钟内快速验证 VisionCart 的核心闭环：登录、拍照/相册识物、国内/海外平台路由、跨平台比价、自然语言筛选、收藏、价格提醒、历史恢复与悬浮窗识物。

## 1. 验证前置条件

| 项目 | 要求 |
| --- | --- |
| 后端服务 | MySQL、Redis 已启动，后端运行在 `http://localhost:8080` 或评审环境指定地址 |
| Android 客户端 | 已安装 Debug APK，`VISIONCART_API_BASE_URL` 指向后端地址 |
| 外部能力 | `.env` 已配置视觉模型、SMTP 邮箱验证码、至少一个商品检索平台密钥 |
| 区域路由 | 如需验证国内/海外平台切换，需配置 `visioncart.geoip.database-path` 或 `GEOIP_DATABASE_PATH`，并通过国内/海外出口 IP 或可信代理请求头模拟不同地区 |
| 测试账号 | 准备一个可收验证码的邮箱，例如 `judge@example.com` |
| 测试图片 | 准备 1 张清晰商品图片，建议使用常见实物：耳机、水杯、牙膏、鼠标、运动鞋等 |

后端快速检查：

```bash
curl http://localhost:8080/api/v1/health
```

通过标准：返回 JSON 中 `code` 为 `200`，`data.status` 为 `up`。

## 2. 最小验证用例总览

| 编号 | 功能 | 标准操作路径 | 通过标准 |
| --- | --- | --- | --- |
| VC-P0-01 | 邮箱验证码登录 | 打开 App → 输入邮箱 → 获取验证码 → 输入 6 位验证码 → 点击“登录 / 注册” | 进入首页，顶部显示用户邮箱前缀；重启 App 后仍保持登录 |
| VC-P0-02 | 商品识别与异步结果 | 首页 → 点击“拍照识物”或从相册选择测试图片 → 等待识别完成 | 页面显示商品类目、属性、图片预览；无崩溃或长时间空白 |
| VC-P0-03 | 国内/海外平台路由 | 使用国内出口搜索一次，再使用海外出口搜索一次 | 国内请求只调用国内平台策略；海外请求只调用国际平台策略，例如 eBay |
| VC-P0-04 | 跨平台商品检索与比价 | 完成识别后停留首页 → 等待“匹配商品”列表加载 | 列表显示商品标题、平台、价格、图片；结果数大于 0；价格可对比 |
| VC-P0-05 | 自然语言筛选/排序 | 在底部“追加筛选”输入：`只看更便宜的`、`按销量排序` 或 `只看口碑好的` → 点击提交 | 商品列表刷新或排序变化；筛选标签/状态提示出现；可点击“撤销”恢复 |
| VC-P0-06 | 收藏与收藏同步 | 在任一商品卡点击收藏图标 → 底部进入“收藏”页 | 收藏页出现该商品；再次点击移除后不再显示 |
| VC-P1-07 | 价格提醒 | 收藏页 → 点击目标商品的提醒入口 → 输入高于当前价或合理目标价 → 确认 | 商品显示已设置提醒；重新进入收藏页仍可看到提醒状态；可删除提醒 |
| VC-P1-08 | 历史记录恢复 | 完成一次识别后 → 底部进入“历史”页 → 点击最新历史记录 | 回到首页并恢复识别属性、图片/缩略图和当时商品列表 |
| VC-P1-09 | 悬浮窗截图识物 | 首页右上角开启悬浮窗 → 授权悬浮窗/录屏 → 在其他 App 或网页展示商品图 → 点击悬浮球截图并框选 → 点击“识别” | 悬浮面板显示识别进度、商品结果和筛选输入框 |

## 3. 标准操作路径

### VC-P0-01 邮箱验证码登录

1. 启动 VisionCart App。
2. 在登录页输入评审邮箱。
3. 点击获取验证码。
4. 从邮箱收件箱读取标题为 `VisionCart 验证码` 的 6 位验证码。
5. 回到 App 输入验证码，点击“登录 / 注册”。
6. 观察是否进入首页。

预期结果：

- 首页底部出现“首页 / 收藏 / 历史”导航。
- 顶部用户区域显示邮箱前缀。
- 关闭并重新打开 App 后，无需重新登录。

失败判定：

- 验证码无法发送或接口返回错误。
- 输入正确验证码后仍停留登录页。
- 登录后接口请求出现 401。

### VC-P0-02 商品识别与异步结果

1. 在首页点击“拍照识物”，拍摄准备好的商品。
2. 若评审设备不方便拍摄，可使用首页相册入口选择商品图片。
3. 等待识别进度完成。
4. 查看识别区域。

预期结果：

- 页面出现上传图片预览。
- 识别区域显示类目，例如“数码 / 耳机”或相近类目。
- 属性区域显示至少 2 个可读属性，例如品牌、颜色、品类、规格等。
- 如果识别出多个候选商品，可选择一个候选继续检索。

失败判定：

- 一直停留在加载态超过 60 秒。
- 识别完成但无类目、无属性、无错误提示。
- App 崩溃或返回登录页。

### VC-P0-03 国内/海外平台路由

说明：当前实现由后端 `RegionResolver` 根据请求 IP 做 GeoIP 判断，不读取手机 GPS。GeoIP 不可用、IP 查不到、本地地址或内网地址都会默认按国内处理。平台默认策略为：拼多多、淘宝走 `domestic`，eBay 走 `international`。

1. 确认后端已配置 GeoIP 数据库路径，或评审环境已能让后端识别真实出口 IP。
2. 在国内网络环境中完成一次识别和商品搜索。
3. 观察商品卡平台字段，或查看后端日志中的平台搜索记录。
4. 切换到海外出口网络，或通过可信反向代理转发海外 IP 后再次执行同样搜索。
5. 再次观察商品卡平台字段和后端日志。

预期结果：

- 国内请求只命中 `region-strategy=domestic` 的平台，例如拼多多、淘宝。
- 海外请求只命中 `region-strategy=international` 的平台，例如 eBay。
- 后端日志可看到不适配地区的平台被跳过，例如 `regionStrategy=domestic not suitable for international request`。
- 搜索缓存区分国内/海外，同一商品属性在不同地区不会复用错误平台结果。

失败判定：

- 国内出口仍调用 eBay，或海外出口仍调用淘宝/拼多多。
- GeoIP 未配置时误以为已完成海外验证；此时只能证明默认国内兜底可用。
- 商品列表的平台字段与后端实际调用平台不一致。

### VC-P0-04 跨平台商品检索与比价

1. 延续 VC-P0-02 或 VC-P0-03，不离开首页。
2. 等待“匹配商品”区域加载。
3. 向下滚动查看商品卡片。
4. 点击任意商品卡片进入详情页，再返回。

预期结果：

- “匹配商品”区域显示结果数量。
- 商品卡包含标题、价格、平台、图片，部分商品可显示销量、口碑或自营标识。
- 至少展示一个可点击商品；详情页打开对应商品链接或 WebView 页面。
- 不同商品价格能直观看到差异，完成基本比价。

失败判定：

- 搜索结果为空且没有“放宽条件”或错误说明。
- 商品卡缺少价格或平台信息。
- 点击商品详情无响应且无提示。

### VC-P0-05 自然语言筛选/排序

1. 延续 VC-P0-04，确保页面已有商品列表。
2. 在底部输入框输入以下任一指令：
   - `只看更便宜的`
   - `按销量排序`
   - `只看口碑好的`
3. 点击提交按钮。
4. 观察筛选状态、商品顺序和结果数量。
5. 如页面出现“撤销”，点击撤销。

预期结果：

- 页面出现“正在筛选”或类似状态。
- 商品列表刷新，排序或结果范围发生变化。
- 筛选摘要或标签显示当前筛选条件。
- 点击“撤销”后回到上一轮商品列表或筛选状态。

失败判定：

- 提交后没有任何反馈。
- 筛选失败后没有保留原结果或错误提示。
- 撤销按钮出现但点击无效。

### VC-P0-06 收藏与收藏同步

1. 在首页商品列表中选择一个商品。
2. 点击商品卡上的收藏图标。
3. 切换到底部“收藏”页。
4. 找到刚收藏的商品。
5. 点击移除收藏，再刷新或重新进入收藏页。

预期结果：

- 收藏后商品立即出现在收藏页。
- 收藏页商品显示标题、平台、价格。
- 移除后该商品从收藏页消失。
- 重新打开 App 后，收藏状态与后端保持一致。

失败判定：

- 收藏按钮点击后无状态变化。
- 收藏页为空或显示其他用户数据。
- 删除收藏后再次进入仍显示已删除商品。

### VC-P1-07 价格提醒

1. 先完成 VC-P0-06，确保收藏页至少有 1 个商品。
2. 在收藏页点击该商品的价格提醒入口。
3. 输入目标价格。为了快速验证保存能力，可输入略低于当前价的金额。
4. 点击确认。
5. 退出收藏页后重新进入。
6. 再次打开提醒弹窗，点击删除提醒。

预期结果：

- 保存后商品显示已设置提醒状态。
- 重新进入收藏页后提醒状态仍存在。
- 删除提醒后提醒状态消失。

失败判定：

- 非收藏商品也能创建提醒。
- 保存成功提示后重新进入丢失。
- 删除提醒失败或状态不更新。

### VC-P1-08 历史记录恢复

1. 至少完成一次识别和商品检索。
2. 点击底部“历史”页。
3. 找到最新识别记录。
4. 点击该历史记录。
5. 返回首页观察恢复状态。

预期结果：

- 历史页展示识别时间、类目或图片缩略信息。
- 点击历史后恢复到首页。
- 首页恢复识别属性、筛选条件和历史商品列表。
- 可基于恢复结果继续执行自然语言筛选或收藏。

失败判定：

- 完成识别后历史页无记录。
- 点击历史记录无响应。
- 恢复后仅有空页面，无法继续筛选或收藏。

### VC-P1-09 悬浮窗截图识物

1. 在首页点击右上角悬浮窗按钮。
2. 按系统提示授权悬浮窗权限和屏幕录制权限。
3. 打开浏览器、相册或购物 App，展示一张商品图片。
4. 点击 VisionCart 悬浮球。
5. 选择截图识物，框选商品区域。
6. 点击“识别”。
7. 在悬浮面板查看识别和商品结果。

预期结果：

- 悬浮球可在其他 App 上方显示。
- 框选页面可正常拖拽选择区域。
- 悬浮面板显示识别进度、商品结果、筛选输入框。
- 点击“重新截图”可再次触发流程，点击“收起”可折叠面板。

失败判定：

- 授权后悬浮球不出现。
- 截图为空白或无法框选。
- 悬浮面板无法显示识别结果。

## 4. API 辅助验证路径

评委如需绕过 App 快速确认后端能力，可使用以下接口。除健康检查外，均需要登录后携带 `Authorization: Bearer <token>`。

| 功能 | 方法与路径 | 用途 |
| --- | --- | --- |
| 健康检查 | `GET /api/v1/health` | 检查服务是否启动 |
| 发送验证码 | `POST /api/v1/auth/send-code` | 登录前发送邮箱验证码 |
| 登录 | `POST /api/v1/auth/login` | 获取 JWT |
| 识别图片 | `POST /api/v1/recognition/analyze` | 上传图片并创建识别任务 |
| 查询识别状态 | `GET /api/v1/recognition/status/{sessionId}` | 轮询异步识别结果 |
| 商品检索 | `POST /api/v1/search/products` | 根据识别属性检索商品 |
| 自然语言筛选 | `POST /api/v1/nlp/filter` | 对候选商品执行筛选 |
| 收藏列表 | `GET /api/v1/favorites` | 校验收藏同步 |
| 历史列表 | `GET /api/v1/history` | 校验识别历史 |
| 价格提醒 | `GET /api/v1/price-alerts` | 校验提醒保存状态 |

## 5. 推荐评审顺序

1. 后端健康检查。
2. 邮箱验证码登录。
3. 拍照或相册识别。
4. 商品检索与比价。
5. 自然语言筛选和撤销。
6. 收藏、价格提醒。
7. 历史恢复。
8. 有时间再验证悬浮窗截图识物。

P0 用例全部通过即可证明核心购物比价闭环可用；P1 用例用于验证增强体验和数据持久化能力。
