# VisionCart 目录结构与启动说明

## 1. 项目总体说明

VisionCart 是一个 AI 智能比价购物助手，核心能力包括：

- 拍照识物：用户拍摄商品图片，后端调用视觉模型识别商品类目、品牌、颜色、规格、外观等属性。
- 多商品选择：一张图片中检测到多个商品时，先让用户选择目标商品，再继续识别和搜索。
- 商品搜索与比价：按识别结果从淘宝、拼多多、eBay 等平台召回商品，并进行过滤、排序和去重。
- 自然语言筛选：用户可以输入“低于 50”“适合年轻人”“有线的”“可以带上飞机”等自然语言条件，后端将其解析成结构化筛选/偏好。
- AI 导购与建议卡片：基于当前商品池生成排序、筛选、洞察类建议。
- 收藏、历史、价格提醒：支持识别历史、商品收藏和价格提醒。

项目采用 Gradle 多模块结构：

```text
VisionCart/
├── backend/                  Spring Boot 后端模块
├── android/app/              Android 客户端模块
├── data/                     运行时数据文件，例如 GeoIP 数据库
├── deploy/                   部署、Docker Compose、监控配置
├── docs/                     项目补充文档
├── scripts/                  辅助脚本
├── gradle/                   Gradle Wrapper 依赖
├── .env.example              后端环境变量模板

├── README.md                 项目总说明
```

### 2.2 api/controller

REST API 控制器层，负责接收 HTTP 请求、做基础权限检查、调用 service，并返回统一响应。

主要控制器：

```text
api/controller/
├── AuthController.java                  邮箱验证码登录、刷新 token、退出登录
├── RecognitionController.java           图片识别、识别状态、多商品选择、属性候选
├── SearchController.java                商品搜索入口
├── NlpFilterController.java             旧 NLP 筛选兼容入口
├── ActionUndoController.java            统一用户动作入口与撤回入口
├── SuggestionController.java            建议卡片、AI 洞察
├── AttributeCorrectionController.java   属性修正入口
├── UserDataController.java              收藏、历史等用户数据
├── PriceAlertController.java            价格提醒
├── MetricsController.java               业务指标
└── HealthController.java                健康检查
```

重点接口：

- `POST /api/v1/recognition/analyze`：上传图片并创建异步识别任务。
- `GET /api/v1/recognition/status/{sessionId}`：轮询识别状态。
- `POST /api/v1/recognition/{sessionId}/select`：多商品场景下选择候选商品。
- `POST /api/v1/search/products`：按识别属性和筛选条件搜索商品。
- `POST /api/v1/actions/execute`：统一动作入口，支持 NLP、建议卡片、排序、清空、属性修正等。
- `POST /api/v1/actions/undo`：撤回上一步动作。
- `GET /api/v1/health`：健康检查。

### 2.10 service/recognition

视觉识别与识别流程编排。

```text
service/recognition/
├── RecognitionOrchestrator.java         识别主编排器
├── AsyncRecognitionTaskManager.java     Redis 中的识别任务状态管理
├── VisionModelService.java              视觉模型接口
├── DoubaoVisionClient.java              豆包视觉模型实现
├── AliyunQwenVisionClient.java          通义千问视觉模型实现
├── ImageProcessor.java                  图片预处理、裁剪
├── RecognitionImageStorage.java         识别图片与候选裁剪图存储
├── MultiProductDetector.java            多商品检测
├── AttributeCorrectionService.java      属性修正与重新召回
├── RecognitionResultValidator.java      视觉识别结果清洗校验
└── ...
```

关键流程：

1. Android 上传图片到 `/api/v1/recognition/analyze`。
2. 后端创建 sessionId，并进入异步识别。
3. 图片先做多商品检测。
4. 如果候选数达到阈值，状态进入 `MULTI_PRODUCT_PENDING`，前端展示选择弹窗。
5. 如果是单商品或用户已选择候选，则调用视觉模型识别。
6. 识别完成后生成商品属性，并触发搜索。

### 2.11 service/search

搜索、区域路由、平台调用、意图过滤和排序，是后端核心模块之一。

```text
service/search/
├── SearchOrchestrator.java              搜索主编排器
├── PlatformSearchService.java           平台搜索接口
├── PddSearchService.java                拼多多搜索
├── TaobaoSearchService.java             淘宝联盟搜索
├── EbaySearchService.java               eBay 搜索
├── EbayQueryTranslator.java             eBay 中文搜索词转英文
├── RegionResolver.java                  GeoIP/手动区域模式判断
├── ProductIntentBuilder.java            从识别属性构建商品意图
├── QueryPlanner.java                    生成分层搜索词
├── IntentGate.java                      国内中文意图过滤
├── OverseasEnglishIntentMatcher.java    海外英文意图过滤
├── RelevanceRanker.java                 相关性排序
├── IntentAwareSorter.java               意图分层排序
├── SearchCandidatePool.java             候选池快照
├── SearchRunService.java                搜索运行态与重排
├── CandidateSessionCache.java           Redis 候选池缓存
├── PlatformCircuitBreaker.java          平台熔断
├── ProductDeduplicator.java             商品去重
├── ProductSortService.java              价格/销量/评分等排序
├── PowerBankProductClassifier.java      充电宝成品/配件分类
└── ...
```

搜索区域模式：

- `auto`：默认模式，后端根据 GeoIP 判断国内/海外。
- `domestic`：强制国内，只走国内平台。
- `international`：强制海外，当前主要走 eBay。

国内与海外过滤逻辑是分开的：

- 国内：继续使用原来的中文 taxonomy 与 `IntentGate` / vertical strategy。
- 海外：使用 `OverseasEnglishIntentMatcher` 处理英文标题，避免国内中文规则误杀 eBay 商品。

### 2.12 service/nlp

自然语言理解、语义计划、状态栈和校验。

```text
service/nlp/
├── LlmSemanticPlanner.java                  LLM 语义计划入口
├── SemanticPlannerModelService.java         LLM 调用与 JSON 解析
├── SemanticActionPlanValidator.java         语义计划白名单校验
├── SemanticPlanConstraintProvenanceGuard.java 属性硬筛来源保护
├── SemanticExecutionPolicy.java             执行策略修正
├── NlpConversationManager.java              当前筛选状态
├── NlpStateStackService.java                连续 NLP 状态栈
└── ...
```

主要设计：

- LLM 每轮输出“当前完整目标状态”。
- 后端对 intent、executionMode、operator、sort 等字段做白名单校验。
- `attribute:<属性名>` 只允许来自用户历史话术或当前话术中的明确属性词。
- 异常 LLM 输出会被清洗、丢弃或回退，不直接污染筛选状态。


## 9. 后端启动方式

先确保 MySQL 和 Redis 已启动，并已创建数据库：

```sql
CREATE DATABASE visioncart CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

运行测试：

```powershell
.\gradlew.bat :backend:test --no-daemon
```

构建后端 jar：

```powershell
.\gradlew.bat :backend:bootJar --no-daemon
```

启动后端：

```powershell
java -jar backend\build\libs\backend-0.1.0.jar
```

健康检查：

```powershell
curl http://localhost:8080/api/v1/health
```

## 10. Android 启动方式

在项目根目录创建 `local.properties`，配置后端地址：

```properties
VISIONCART_API_BASE_URL=http://你的后端IP:8080/
```

构建 Debug APK：

```powershell
.\gradlew.bat :android:app:assembleDebug --no-daemon
```

安装到真机：

```powershell
adb install -r android\app\build\outputs\apk\debug\app-debug.apk
```

如果使用本地后端并通过 USB 调试连接真机，可按需使用：

```powershell
adb reverse tcp:8080 tcp:8080
```
