# VisionCart 项目分工说明

## 一、团队情况

VisionCart 项目由王励宏和汤潘两名成员共同完成。项目围绕“拍照识别商品、多平台搜索比价、收藏管理和价格提醒”这一完整流程展开，既包含 Spring Boot 后端服务，也包含 Android 客户端开发。

在分工上，我们采用“模块主责、共同联调”的方式推进。王励宏主要负责后端服务和核心业务逻辑，汤潘主要负责 Android 客户端和用户交互体验。两人各自承担主要开发任务，同时在接口设计、功能联调、测试和文档整理上共同配合，保证项目整体能够顺利运行。

## 二、成员分工

### 2.1 王励宏：后端服务与核心业务

王励宏主要负责项目后端部分的设计与实现，包括后端工程搭建、数据库设计、接口开发、用户认证、AI 识别对接、商品搜索比价和价格提醒等内容。

具体来说，王励宏负责实现邮箱验证码登录和 JWT 鉴权，保证用户能够安全访问系统接口；负责图片识别相关接口的设计与开发，将用户上传的商品图片交给视觉模型识别，并把识别结果整理成商品名称、品牌、类别、规格等结构化信息；负责对接拼多多、淘宝联盟、eBay 等平台的商品搜索服务，对不同平台的商品结果进行整合，返回给客户端用于比价展示。

此外，王励宏还负责收藏商品、价格历史和价格提醒相关的后端逻辑，包括目标价提醒、降价提醒等功能；同时维护后端接口文档和 Swagger 页面，方便客户端调试和项目验收。

### 2.2 汤潘：Android 客户端与用户体验

汤潘主要负责 Android 客户端部分的设计与开发，包括客户端工程搭建、页面开发、拍照识别入口、商品结果展示、本地缓存、网络请求封装和悬浮窗功能等内容。

具体来说，汤潘负责实现邮箱验证码登录页面，并在客户端保存用户登录状态；负责使用 CameraX 完成拍照功能，将商品图片提交给后端识别，并展示识别结果；负责商品搜索结果页面和商品卡片设计，让用户能够直观看到不同平台的商品价格、图片、来源和跳转入口。

同时，汤潘还负责收藏列表、识别历史和商品详情等页面开发，并使用 Room 数据库进行本地缓存；负责悬浮球、截图识别入口和悬浮面板等交互功能，让用户在不同使用场景下都能更方便地进行商品识别和比价。

## 三、协作方式

项目开发过程中，两名成员并不是完全分开开发，而是围绕完整业务流程进行配合。后端接口开发前，王励宏会和汤潘确认接口字段、请求格式和返回内容；客户端接入过程中，汤潘会及时反馈页面展示需要的数据和接口调用中遇到的问题。

在联调阶段，两人共同测试了登录、拍照识别、商品搜索比价、收藏商品和价格提醒等核心流程，并一起修复字段不一致、异常提示不清楚、页面状态缺失等问题。项目后期，两人也共同完成了运行环境整理、演示流程准备和项目文档完善。
